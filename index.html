Get your messages

Export from one or more of these, then choose the files above.

SMS & MMS

Android phones

  1. Install SMS Backup & Restore on your phone.
  2. Back up Messages, and Calls too if you want call stats.
  3. Copy the backup files to this computer, or save them to a cloud drive and download them.

Choose sms-….xml and, optionally, calls-….xml

Google Play ↗ Help ↗

Google Chat

Google Takeout

  1. Open Google Takeout and click Deselect all.
  2. Tick Google Chat, then Next step → Export once, .zip → Create export.
  3. When Google emails you, download every part of the export.

Choose takeout-….zip, all parts together if it was split

Dates are only understood when your Google account language is English.

Open Google Takeout ↗

WhatsApp

Android or iPhone

  1. Open a chat, then ⋮ (Android) or the contact or group name (iPhone).
  2. Tap Export chat, with or without media, and send it to yourself.
  3. Repeat for every chat you want to include.

Choose WhatsApp Chat with ….txt or WhatsApp Chat - ….zip

Exports don't say which sender is you. Yapalytics guesses, and you can correct it under You on WhatsApp.

How to export a chat ↗

iMessage

On a Mac

  1. Install the free imessage-exporter with Homebrew: brew install imessage-exporter
  2. Run it. Add -c clone to copy attachments too. imessage-exporter -f txt
  3. It writes one .txt per conversation to ~/imessage_export.

Choose the .txt files, or a .zip of the folder

Terminal needs Full Disk Access (System Settings → Privacy & Security). To read an iPhone backup instead, add -p and the backup folder.

GitHub ↗ Homebrew ↗

Telegram

Telegram Desktop

  1. Install Telegram Desktop on a computer and sign in.
  2. Open Settings → Advanced → Export Telegram data. For one chat, use its ⋮ menu → Export chat history.
  3. Set Format to Machine-readable JSON and export.

Choose result.json, or a .zip of the export folder to see photos

The HTML format can't be read. The lighter Telegram for macOS app has no export, so use Telegram Desktop.

Telegram Desktop ↗ About exports ↗

Instagram

Download your information

  1. In Instagram, open Settings → Accounts Center → Your information and permissions → Export your information, then Create export → Export to device.
  2. Under Customize information, pick Messages (add Personal information so the app knows which sender is you). Set Date range to All time and Format to JSON.
  3. When Instagram says it's ready, download the .zip. Large exports come in several parts; download them all.

Choose the .zip, or every part together

The HTML format can't be read. Message requests you never accepted are left out.

Export your information ↗ Help ↗

Messenger

Facebook, plus encrypted chats

  1. On Facebook, open Accounts Center → Your information and permissions → Export your information, then Create export → Export to device. Pick Messages (and Personal information, so the app knows which sender is you), All time and JSON.
  2. That export leaves out end-to-end encrypted chats, which Messenger has used for personal chats since late 2023. Get those on a computer in Messenger: Settings → Privacy & safety → End-to-end encrypted chats → Message storage → Download secure storage data.
  3. Download both. Large Facebook exports come in several parts; download them all.

Choose the .zip files together

The HTML format can't be read. Encrypted chats are only there if secure storage was turned on. Message requests are left out.
